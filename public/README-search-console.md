# Google Search Console Verification

This directory contains a verification file for Google Search Console. The file `google9f6d3d1e2c59f5b2.html` is a placeholder and should be replaced with the actual verification file from Google Search Console.

## How to Get Your Verification File

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Click "Add Property" and enter your website URL
3. Select "URL prefix" verification method
4. Choose the "HTML file upload" verification method
5. Download the HTML verification file provided by Google
6. Replace the placeholder file in this directory with the downloaded file
7. Deploy your website to verify ownership

## Why This Is Important

Google Search Console provides valuable insights about your website's performance in Google search results, including:

- How often your site appears in Google search results
- Which search queries bring users to your site
- How many users click through to your site
- Which pages are indexed and which have issues
- Mobile usability issues
- Core Web Vitals performance metrics

Having a verified Google Search Console account is essential for SEO monitoring and optimization.

## Next Steps After Verification

Once your site is verified:

1. Submit your sitemap.xml file in Search Console
2. Request indexing of important pages
3. Monitor for crawl errors and fix them
4. Check for mobile usability issues
5. Monitor Core Web Vitals performance
6. Set up email notifications for critical issues

The sitemap generator script we've added to the build process will ensure your sitemap is always up to date.
